## Tabliss의 유지 관리 포크

이 저장소는 Firefox와 Chrome을 위한 사용자 설정형 새 탭 페이지인 Tabliss의 유지 관리 포크입니다. 원 프로젝트는 1년 넘게 업데이트가 중단되었고 아직 병합되지 않은 풀 리퀘스트가 많이 남아 있었습니다. TablissNG는 원 저장소를 기반으로 대부분의 보류 중인 풀 리퀘스트를 병합하여 개선 사항과 버그 수정 사항을 반영하고, Tabliss를 최신 상태로 유지하기 위해 계속 관리합니다.

### 다음 계획

- 지속적인 업데이트와 버그 수정
- 커뮤니티 기여 기능 추가
- 의존성 최신 상태 유지

원 프로젝트의 기여자이거나 개선 아이디어가 있다면 이슈를 열거나 풀 리퀘스트를 제출해 주세요. 함께 Tabliss를 계속 발전시켜 나갈 수 있습니다.

### 기여 아이디어를 찾고 있나요?

아직 구현되지 않은 요청 기능 목록은 [GitHub 프로젝트](https://github.com/users/BookCatKid/projects/3?query=sort%3Aupdated-desc+is%3Aopen)에서 확인할 수 있습니다. `in progress` 상태가 아닌 항목은 대부분 자유롭게 작업할 수 있습니다.

## Tabliss 대비 주요 개선 사항

아래 목록이 전부는 아닙니다. TablissNG에는 여기에 적지 않은 다양한 조정, 사용성 개선, 기능이 포함되어 있습니다.

- 사용자 설정
  - 사용자 지정 검색 엔진과 브라우저 기본값 지원
  - 표시 및 글꼴 설정의 다양한 스타일 옵션(크기 조절, 밑줄, 텍스트 외곽선, 사용자 지정 CSS 클래스 등)

- 위젯
  - 시간 추적기, Bitcoin Mempool, 자주 방문한 사이트, 이진 시계, 북마크, 사용자 지정 HTML
  - 개선 기능: 할 일의 일일 루틴, 인용문의 성경 구절, 메모의 Markdown
  - 위젯을 자유롭게 배치할 수 있는 `Free Move` 모드

- 배경 및 시각 효과
  - Wikimedia 오늘의 이미지, NASA APOD, Giphy 오늘의 이미지
  - 동영상, GIF, 온라인 이미지 URL 지원
  - 자동 야간 어둡게 표시와 무작위 그라디언트

- 인터페이스 및 접근성
  - 완전한 다크 모드
  - 모든 설정의 전체 번역 지원

## 로컬에서 실행

로컬 개발에는 Node.js와 pnpm이 필요합니다. 최신 버전을 사용하면 됩니다.

먼저 저장소를 복제합니다.

```sh
git clone https://github.com/BookCatKid/TablissNG.git
cd TablissNG
```

그다음 의존성을 설치합니다.

```sh
pnpm install
```

### 사용 가능한 명령

- `pnpm run dev` — 로컬 개발 서버 시작
- `pnpm run build` — 프로젝트 빌드
- `pnpm run test` — 테스트 실행
- `pnpm run translations` — 번역 파일 추출 및 동기화(자세한 내용은 [TRANSLATING.md](../../TRANSLATING.md) 참고)
- `pnpm run translations status` — 번역 상태 표시(예: `pnpm run translations status fr`)
- `pnpm run translations create` — 새 로케일 파일 생성(예: `pnpm run translations create de-AT`)
- `pnpm run translations migrate` — 이름이 바뀐 번역 키 마이그레이션(예: `pnpm run translations migrate --map old.id=new.id`)
- `pnpm run lint:fix` — `--fix` 옵션으로 ESLint 실행(검사만 하려면 `pnpm run lint`)
- `pnpm run prettier` — `--write` 옵션으로 Prettier 실행(검사만 하려면 `pnpm run prettier:check`)
- `pnpm run deps:update` — 대화형 의존성 업데이트 도구 실행(업데이트 확인만 하려면 `pnpm run deps:check`)

기본적으로 빌드와 개발 서버는 웹 버전을 대상으로 합니다. 플랫폼을 지정하려면 명령 뒤에 `:chromium` 또는 `:firefox`를 붙이세요.

```sh
pnpm run dev:chromium
pnpm run build:firefox
```

### 환경 변수

외부 서비스를 사용하려면 API 키를 발급받아 `.env` 파일에 입력해야 합니다. 먼저 예제 파일을 복사합니다.

```sh
cp .env.example .env
```

그다음 API 키를 입력합니다.

```ini
GIPHY_API_KEY=your_key_here
UNSPLASH_API_KEY=your_key_here
NASA_API_KEY=your_key_here
TRELLO_API_KEY=your_key_here # Trello 앱 설정에서 올바른 리디렉션 URI를 지정해야 합니다. Firefox와 Chromium에서는 각각 아래 URI를 사용할 수 있습니다: https://53dad6be72180770ccc08f0a6e2fc8a64dcf7b42.extensions.allizom.org 및 https://dlaogejjiafeobgofajdlkkhjlignalk.chromiumapp.org
```
